# 금융 시스템 백엔드 저장소 초기 설계

## 목적

금융 거래 시스템의 정합성, 동시성, 트랜잭션, 멱등성, 장애 복구 문제를 8주 동안 직접 재현하고 해결한 과정을 기록하는 비공개 저장소를 만든다.

## 초기 범위

- 저장소 이름은 `financial-system-backend`로 한다.
- GitHub 공개 범위는 Private으로 한다.
- 기본 브랜치는 `main`으로 한다.
- 초기 커밋에는 프로젝트 목적, 진행 원칙, 확정된 8주 계획을 담은 README와 저장소 초기 설계 기록을 포함한다.
- 기술 스택, ERD, API, 애플리케이션 골격은 1주차 도메인 및 불변식 설계가 끝난 뒤 결정한다.

## 진행 기준

모든 주차는 `문제 발견 → 직접 설계 → 구현 → 실패 및 검증 → 개선`의 순서를 따른다. 설계 기록에는 성공한 최종안뿐 아니라 최초 설계, 실패 조건, 검토한 대안, 선택 근거와 측정 결과를 남긴다.

## 성공 조건

- GitHub에서 저장소가 Private으로 표시된다.
- 기본 브랜치가 `main`이다.
- README에 확정된 8주 계획과 프로젝트 진행 원칙이 빠짐없이 들어 있다.
- 초기 단계에는 특정 기술 스택이나 구조를 선결정하지 않는다.
