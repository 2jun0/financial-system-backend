# S-202 — 수취 계좌 없음

상태: 확정

## 목적

수취 은행이 계좌가 없다고 응답하면 중앙 결제 시스템이 결제를 거절하고 결제잔액을 변경하지 않는지 확인한다.

## 사전 조건

- 은행 B에 수취 계좌 `B-404`는 없다.
- 송금액은 10,000원, 송금 키는 `E-202`이다.
- 두 은행의 중앙 결제잔액은 각각 1,000,000원이다.
- 요청과 응답은 정상적으로 전달된다.

## 사건 순서

1. 은행 A가 중앙 결제 시스템에 `E-202` 결제를 요청한다.
2. 중앙 결제 시스템이 `수취검증대기` 결제를 저장하고 은행 B에 수취 검증을 요청한다.
3. 은행 B가 `B-404`가 없음을 확인하고 수취 불가를 응답한다.
4. 중앙 결제 시스템이 `수취검증대기`인 결제를 `결제거절`로 변경한다.
5. 중앙 결제 시스템이 은행 B에 `결제거절` 결과를 통지한다.
6. 은행 B는 수취 기록이 없으므로 새 기록을 생성하지 않고 처리를 종료한다.
7. 중앙 결제 시스템이 은행 A에 `결제거절`을 응답한다.

## 사건 흐름

```mermaid
sequenceDiagram
    autonumber
    participant A as 은행 A
    participant C as 중앙 결제
    participant B as 은행 B
    A->>C: E-202 결제 요청
    C->>C: 수취검증대기 저장
    C->>B: 수취 검증 요청
    B-->>C: 계좌 없음, 수취 불가
    C->>C: 결제거절 저장
    C->>B: 결제거절 결과 통지
    B->>B: 수취 기록 없음, 변경 없이 종료
    C-->>A: 결제거절
```

## 기대 결과

- 중앙 결제는 `결제거절`이다.
- 두 은행의 결제잔액은 각각 1,000,000원으로 유지된다.
- 수취 은행에 결제거절 결과를 한 번 통지한다.
- 수취 은행은 통지를 받아도 수취 기록을 새로 생성하지 않으며 잔액을 변경하지 않는다.

## 금지되는 결과

- 존재하지 않는 계좌에 대한 결제를 완료한다.
- 수취 불가 응답을 받은 뒤 송금 은행의 결제잔액을 확인한다.
- 결제잔액 일부만 변경한다.
